# Проверки чат-виджета ИИ-ассистента

Виджет — это обычный JavaScript в браузере, поэтому для его проверки нужен
DOM. Здесь используется **jsdom** — браузер без графического интерфейса: он
выполняет код виджета по-настоящему (создаёт элементы, обрабатывает клики,
читает ответ), но не требует запускать Chrome.

## Запуск

```bash
# 1. В отдельном терминале запускаем бэкенд (виджет обращается к нему)
npm start

# 2. В этой же папке server запускаем проверки
npm run test:widget
```

Проверки обращаются к реальному бэкенду на `http://localhost:3000`.
Языковая модель не требуется: подойдёт и режим «поиск по базе знаний»,
в который ассистент переходит автоматически, если Ollama не запущена.

## Что проверяется

| Файл | Что проверяет |
|---|---|
| `verify-widget.mjs` | построение интерфейса, открытие панели, загрузка подсказок и статуса модели, вопрос и потоковый ответ, отображение источников и кнопок оценки, сохранение истории диалога, сброс, **защита от XSS** (вредоносный текст в ответе остаётся текстом) |
| `verify-vite-module.mjs` | что виджет корректно экспортируется и работает как модуль ES (сборка Vite), относительный путь `/api` и передача контекста корзины |
| `verify-front-pages.mjs` | виджет на **реальных HTML-страницах** статичного сайта: подключение на всех страницах, отсутствие поломок в скриптах сайта, передача корзины в ассистента |

Итого 59 проверок: 35 + 11 + 13.

## Особенности

* `verify-front-pages.mjs` берёт страницы из соседней папки
  `gravity-cafe-front`. Если её нет, проверка аккуратно пропускается.
  Путь можно задать вручную:

  ```bash
  GRAVITY_FRONT_DIR=/путь/к/gravity-cafe-front npm run test:widget
  ```

* Адрес бэкенда для проверки готовности можно переопределить переменной
  `GRAVITY_API_URL` (по умолчанию `http://localhost:3000/api/assistant/health`).

## Зачем это в дипломе

Юнит-тесты проверяют серверную логику, тесты на PostgreSQL — работу с данными,
а эти проверки закрывают клиентскую часть: что гость действительно увидит
ответ, источники и кнопки оценки, что диалог не теряется при перезагрузке
страницы и что ответ ассистента нельзя использовать для внедрения скрипта
в страницу другого гостя.
